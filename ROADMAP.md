# Программа модернизации VK Image Merger Bot

## Приоритет: Высокий

### 1. Защита конфиденциальных данных
- [ ] Вынести токены из `.env` файла в переменные окружения Docker (секреты через `--env-file`)
- [ ] Добавить `.env` в `.gitignore` (если ещё не добавлен)
- [ ] Создать `.env.example` с пустыми значениями для примера

### 2. Обработка ошибок и стабильность
- [ ] Добавить валидацию токенов при старте бота (проверка через API)
- [ ] Обервать вызовы Яндекс.Диска в retry-логику (3 попытки с экспоненциальной задержкой)
- [ ] Добавить ограничение на количество активных сессий пользователей (защита от спама)
- [ ] Обработать случай, когда Яндекс.Диск недостен (fallback: только ручная загрузка)

### 3. Улучшение склейки изображений
- [ ] Добавить горизонтальную склейку (ряд изображений) как альтернативу
- [ ] Поддержка произвольного формата (не только A4 210mm)
- [ ] Добавить настройку DPI через команду бота
- [ ] Контроль максимального размера выходного файли (лимит VK ~200MB)
- [ ] Автоматическое уменьшение DPI при превышении лимита

## Приоритет: Средний

### 4. Расширение функциональности
- [ ] Поддержка более 3 изображений (2-10 шт.)
- [ ] Предпросмотр результата перед сохранением
- [ ] Настройка порядка изображений (перетаскивание / сортировка)
- [ ] Поддержка PNG как выходного формата (с прозрачностью)
- [ ] Добавить водяной знак (текст / лого) на результат

### 5. Улучшение UX
- [ ] Прогресс-бар обработки (промежуточные сообщения)
- [ ] Инлайн-кнопки для выбора режима (вертикаль/горизонт)
- [ ] Поддержка отмены конкретного шага (назад к выбору файлов)
- [ ] Справка по командам через `/help`

### 6. Администрирование
- [ ] Логирование в файл с ротацией (logrotate)
- [ ] Метрики: количество обработок, ошибки, время ответа
- [ ] Команда `/stats` для администратора
- [ ] Graceful shutdown по сигналу SIGTERM
